# Five Night's at Freddys HTML

Colección fan-made de juegos de Five Nights at Freddy's ejecutables desde el navegador.

**Web:** [https://fnaf-en-html.vercel.app/](https://fnaf-en-html.vercel.app/)

## Juegos incluidos

- Five Nights at Freddy's
- Five Nights at Freddy's 2
- Five Nights at Freddy's 3
- Five Nights at Freddy's 4
- Sister Location
- Freddy Fazbear's Pizzeria Simulator
- Ultimate Custom Night
- FNaF World

## Tecnología

El proyecto utiliza HTML, CSS y JavaScript, con una página independiente para cada juego. Los recursos empaquetados se sirven como fragmentos y se reconstruyen en el navegador para que la web pueda alojarse como sitio estático.

No necesita un proceso de compilación local: Vercel sirve directamente los archivos del repositorio.

## Desarrollo y comprobaciones

El workflow **Site integrity checks** verifica los ocho puntos de entrada, la sintaxis de los scripts, el límite de visualización, los recursos requeridos y los 160 fragmentos de los archivos ZIP.
